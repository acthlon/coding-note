## 4. The 20-Point Combined Production Readiness Audit

Prior to final milestone sign-off on Day 40, verify every single engineering invariant:

- [ ] 1. **Zero Serializer Typos:** Discount fields in `materials` and `products` serialize numbers without throwing attribute errors.
- [ ] 2. **Cart 404 Recovery:** `CartView.get_object()` executes `get_or_create()`; new accounts receive HTTP 200 with `items: []`.
- [ ] 3. **Anti-Fraud Assertion:** Paystack webhook asserts `amount` and `currency` match database expectations; rejects tampering with HTTP 400.
- [ ] 4. **15-Minute JWT Rotation:** Stateless access tokens expire in 15 minutes; refresh tokens rotate and blacklist immediately.
- [ ] 5. **Scoped Rate Throttles:** Scoped rate throttles active on `/api/v1/auth/login/` (5/min) and password reset (3/hr).
- [ ] 6. **Zero OpenAPI Schema Errors:** `python manage.py spectacular --validate` returns exactly 0 errors.
- [ ] 7. **Automated Integration Suite:** 100% passing tests for Auth, Cart, Orders, and Webhook idempotency in under 15 seconds.
- [ ] 8. **Deterministic Docker Environment:** Multi-stage `Dockerfile` and `docker-compose.yml` orchestrate web, celery, redis, and Postgres cleanly.
- [ ] 9. **Production Security Headers:** `SECURE_SSL_REDIRECT`, `SECURE_HSTS_SECONDS`, `SESSION_COOKIE_SECURE`, and `CSRF_COOKIE_SECURE` enforced.
- [ ] 10. **Clean Layout Routing:** `<Header />` and `<Footer />` render once in `AppLayout`; zero remount flickering.
- [ ] 11. **$O(1)$ Hash Map Cart Operations:** Cart stores items in `Record<string, CartItem>`, eliminating $O(N)$ linear scans.
- [ ] 12. **Derived Pricing Memoization:** Subtotals, delivery fees, and taxes derived via `useMemo` in $O(U)$ amortized time.
- [ ] 13. **Polymorphic Catalog Engine:** Single `CatalogPage` component dynamically serves `/ready-made`, `/fabrics`, and `/new-arrivals`.
- [ ] 14. **URL Search Parameter State:** Catalog filters synchronize with URL parameters and restore on browser history back/forward.
- [ ] 15. **300ms Debounced Filtering:** Price sliders and search queries debounce network requests by 300ms.
- [ ] 16. **Zero Raw JWTs in LocalStorage:** Access tokens stored exclusively in memory; refresh tokens in `HttpOnly` cookies.
- [ ] 17. **Silent 401 Token Refresh:** Axios response interceptor catches 401, refreshes session transparently, and retries original requests.
- [ ] 18. **Stepped Paystack Integration:** Frontend creates order draft, triggers Paystack inline modal, and processes verified callbacks.
- [ ] 19. **Dynamic SEO & JSON-LD:** Every catalog and product route dynamically updates document titles and Schema.org metadata.
- [ ] 20. **Bundle Optimization:** Route-level code splitting via `React.lazy` maintains initial JavaScript bundle under 150KB.
